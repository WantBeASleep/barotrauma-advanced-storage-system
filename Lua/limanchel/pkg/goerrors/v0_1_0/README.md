# goerrors 0.1.0

Объекты ожидаемых ошибок, обёртки и поиск в дереве причин. Источник исходников — этот репозиторий, каталог `Lua/limanchel/pkg/goerrors/v0_1_0/`. Начальная версия с функциями `new`, `wrap`, `is`, `as`; переход с прежнего API не требуется.

Требуется Lua 5.2. Внешних зависимостей, игрового API и C#-моста нет; пакет предназначен для клиента и сервера. Модуль загружается через `require` без настройки и побочных эффектов.

## Создание и описание

`new(message)` создаёт новый объект. `wrap(message, err, ...)` добавляет контекст к одной или нескольким причинам, сохраняя их по ссылке и в порядке аргументов. Сообщение обязательно строковое, включая пустую строку. Причины обязательны, `nil` не пропускается.

Описание любой совместимой ошибки возвращает `err:error()`. Встроенные объекты также поддерживают `tostring(err)`. Для нескольких причин текст имеет форму `контекст: [причина 1; причина 2]`, для одной — `контекст: причина`. Формат предназначен для человека, без обещания машинного разбора.

**Пример:** обёртки и предварительное форматирование контекста.

```lua
local goerrors = require("limanchel.pkg.goerrors.v0_1_0.goerrors")

local disk = goerrors.new("диск недоступен")
local network = goerrors.new("сеть недоступна")
local err = goerrors.wrap(string.format("сохранение хранилища %s", 42), disk, network)
print(err:error())
-- сохранение хранилища 42: [диск недоступен; сеть недоступна]
```

## Контракт пользовательской ошибки

Ошибка — таблица с методом `error()`, возвращающим строку. Регистрация и наследование от класса пакета не нужны. Необязательный метод `unwrap()` возвращает плотный массив ошибок начиная с индекса 1. У листа он отсутствует либо возвращает пустой массив; результат `nil` недопустим.

Встроенный `unwrap()` возвращает копию массива: изменение списка не меняет состав обёртки. Объекты причин сохраняются по ссылке, их поля пакет не меняет. Внутренние поля и классы встроенных ошибок не являются API.

Потребители возвращают ожидаемый сбой как `nil, err`. Неверное использование API вызывает строковый `error()`/`assert()`; сбои пользовательских методов не маскируются.

## Поиск

`is(err, target)` ищет тот же объект, без сравнения текста и без вызова `__eq`. Для повторяемой причины создавай ошибку один раз и передавай её в обёртки.

`as(err, ErrorClass)` возвращает исходный объект указанного класса с его полями либо `nil`. Поддерживаются `setmetatable(instance, ErrorClass)` и `setmetatable(instance, { __index = ErrorClass })`. Сравниваются ссылки на непосредственную метатаблицу и её собственное поле `__index`; цепочки наследования не обходятся, функция `__index` для сопоставления класса не вызывается. Защищённые метатаблицы, скрывающие класс через `__metatable`, не поддерживаются.

Оба поиска сначала проверяют текущую ошибку, затем целиком каждую ветвь по порядку причин. Первое совпадение завершает поиск, описание не вычисляется. Проверяются только посещённые объекты; заранее корректность всего дерева не гарантируется. Циклы нарушают контракт; один объект в нескольких ветвях допустим. Методы пользовательских ошибок не должны менять дерево во время поиска и получения описания.

`is(nil, nil)` возвращает `true`; ровно один `nil` в `is` даёт `false`. `as(nil, ErrorClass)` возвращает `nil`. Неверные типы непустых аргументов нарушают контракт; `new` и `wrap` не принимают `nil` вместо обязательных аргументов.

**Пример:** ожидаемый отказ с сохранённой причиной.

```lua
local err_storage_full = goerrors.new("хранилище заполнено")

local function place_item()
    return nil, goerrors.wrap("перемещение предмета", err_storage_full)
end

local result, err = place_item()
if not result and goerrors.is(err, err_storage_full) then
    print(err:error())
end
```

**Пример:** извлечение пользовательской ошибки по таблице класса.

```lua
local StorageError = {}
local StorageError_mt = { __index = StorageError }

function StorageError:error()
    return string.format("недоступно хранилище %s", self.storage_id)
end

local original = setmetatable({ storage_id = 42 }, StorageError_mt)
local err = goerrors.wrap("загрузка", original)
local found = goerrors.as(err, StorageError)
if found then
    print(found.storage_id)
end
```

При объединённой таблице класса и метатаблицы достаточно задать `StorageError.__index = StorageError` и передать `StorageError` в `setmetatable`; вызов `as` остаётся таким же.
