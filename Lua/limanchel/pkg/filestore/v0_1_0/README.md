# filestore 0.1.0

Общий пакет локального хранения текстовых файлов по относительным ключам. Источник исходников — этот репозиторий, каталог `Lua/limanchel/pkg/filestore/v0_1_0/`. Начальная версия; миграция с прежнего API не требуется.

Требуются Lua 5.2/MoonSharp, встроенные `Game` и `File` LuaCsForBarotrauma и точная зависимость `limanchel.pkg.goerrors.v0_1_0.goerrors`. Пакет работает на клиенте и сервере независимо, без сети и собственного C#-моста. Проверяемая платформа — LuaCs 1.0.117 для Barotrauma 1.13.5.0.

## Сохранение и загрузка

`require("limanchel.pkg.filestore.v0_1_0.filestore")` не обращается к диску, не создаёт каталоги и не требует настройки.

| Вызов | Успех | Ожидаемый сбой |
| --- | --- | --- |
| `save(key, text)` | `true` | `nil, err` |
| `load(key)` | Строка, включая пустую | `nil, err` |

`save` автоматически создаёт родительские каталоги и полностью заменяет прежнее содержимое. `load` ничего не создаёт и читает текущий файл при каждом вызове, поэтому видит ручные изменения.

Текст — строка без автоматического преобразования значений. Запись использует UTF-8 без добавления BOM; чтение следует текстовому API LuaCs/.NET, включая обработку BOM. Пустая строка и любые переводы строк допустимы. Двоичные данные и некорректный UTF-8 не входят в контракт. Расширение файла пакет не проверяет; сериализацию, значения по умолчанию и момент записи определяет вызывающий код.

Корень — `<Game.SaveFolder>/ModFiles/`. На Windows стандартный путь — `%LocalAppData%/Daedalic Entertainment GmbH/Barotrauma/ModFiles/`; при пользовательском пути сохранений используется он. Каталог и файлы доступны через проводник. Изменение `Game.SaveFolder` влияет на следующую операцию; переноса старых файлов нет.

## Ключи

Ключ — непустой относительный путь с разделителем `/` и именем файла в конце. Запрещены абсолютные пути, обратный слеш, пустые сегменты, `.` и `..`, управляющие символы, `< > : " | ? *`, завершающие сегмент пробелы/точки и Windows-имена устройств, включая варианты с расширением и COM/LPT с надстрочными цифрами ¹/²/³. Суффикс `.filestore-tmp` зарезервирован без учёта регистра во всех сегментах.

Также зарезервированы имена, у которых часть до первой точки заканчивается на `~` и цифры: например, `SETTIN~1.FI~` или `folder~2/file.txt`. Это предотвращает обращение к временным файлам через автоматически создаваемые короткие имена NTFS. Ограничение действует на всех ОС, включая обычные имена такого вида; `notes~draft.txt` допустим.

Ключ не исправляется автоматически и сохраняет регистр. Используй одно написание: чувствительность к регистру зависит от ОС. Первые каталоги выбирает потребитель; пакет не добавляет имя мода или сторону выполнения. Корень `Game.SaveFolder` сохраняет исходные разделители: обратный слеш в имени каталога Linux не заменяется.

## Ошибки

Неверные типы аргументов и недопустимые ключи вызывают строковый `assert` до дисковых операций. Ожидаемые сбои возвращают объект `goerrors`; пакет не логирует и не выбирает запасные пути.

`filestore.errors.not_found` соответствует результату `File.Exists == false`: он не гарантирует различение отсутствующего файла и всех причин недоступности на уровне ОС. `read_failed` означает исключение при определении пути, проверке наличия или чтении; исчезновение файла после проверки может дать эту причину. `write_failed` означает сбой сохранения. Контекст содержит ключ, стадию и доступное описание платформенного сбоя. Объекты причин не изменяй.

## Временная запись и ограничения

Пакет записывает `<целевой файл>.filestore-tmp` в том же каталоге и затем заменяет назначение через `File.Move`. Целевой файл не удаляется отдельной операцией. Сбой записи временного файла сохраняет прежний целевой; при отказе пакет пытается удалить временный файл. Ошибка очистки добавляется к исходной ошибке, не скрывая её. Созданные каталоги остаются.

Оставшийся после аварии временный файл игнорируется при чтении и перезаписывается следующим сохранением того же ключа. Общая уборка и восстановление из временных файлов не выполняются.

Нет межпроцессных блокировок, гарантий сохранности при отключении питания или восстановления после сбоя самой замены. Запись нескольких процессов в один ключ одновременно не поддерживается. Процессы с одинаковым `Game.SaveFolder` и ключом обращаются к одному физическому файлу; автоматического разделения по клиенту/серверу нет. Символические ссылки, junction и подмена каталогов извне не входят в гарантии ограничения путей.

Пакет не предоставляет автосохранение, кеш, резервные копии, удаление или перечисление файлов. Другие форматы потребуют отдельного пересмотра API.

**Пример:** сохранение готового текста и чтение по тому же ключу.

```lua
local filestore = require("limanchel.pkg.filestore.v0_1_0.filestore")

local ok, err = filestore.save("ass/storagecfgs/cfg1.json", '{"key":"значение"}')
if not ok then
   print(err:error())
   return
end
local text, load_err = filestore.load("ass/storagecfgs/cfg1.json")
if not text then
   print(load_err:error())
   return
end
print(text)
```

**Пример:** чтение с проверкой отсутствия файла.

```lua
local filestore = require("limanchel.pkg.filestore.v0_1_0.filestore")
local goerrors = require("limanchel.pkg.goerrors.v0_1_0.goerrors")

local text, err = filestore.load("ass/storagecfgs/cfg1.json")
if not text then
   if goerrors.is(err, filestore.errors.not_found) then
      print("Файл пока не сохранён")
   else
      print(err:error())
   end
end
```

## Проверка в игре

Включить мод с пакетом и LuaCs. В Lua-консоли клиента (`cl_lua`) и отдельно сервера (`lua`) выполнить сохранение через публичный `require` в ключи `filestore-check/client/text.txt` и `filestore-check/server/text.txt`: сначала `"Привет\r\nмир\n"`, затем другой текст для проверки замены. Отдельный ключ сохранить пустой строкой. Каждый вызов должен вернуть `true`.

Через проводник проверить файлы в `<Game.SaveFolder>/ModFiles/filestore-check/`: UTF-8 без добавленного BOM, верные переводы строк, отсутствие `.filestore-tmp` после успеха. Перезапустить соответствующий процесс и прочитать те же ключи: содержимое должно совпасть, включая пустую строку. Внешняя правка файла должна быть видна следующему `load` без перезапуска. Проверочные файлы можно удалить вручную.

Автотесты с подменённым API не подтверждают доступность методов в игре. Проверяется стандартной командой из `docs/development/tooling.md`; если установленная обёртка Busted уже запускает Lua 5.2, повторный параметр `--lua=lua5.2` нужно опустить, сохранив остальные аргументы.
