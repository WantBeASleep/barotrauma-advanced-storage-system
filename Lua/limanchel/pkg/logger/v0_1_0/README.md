# logger 0.1.0

Читаемые сообщения с уровнем и префиксами для передачи настроенного логгера как зависимости.

Источник: [репозиторий мода](https://github.com/WantBeASleep/barotrauma-advanced-storage-system), каталог `Lua/limanchel/pkg/logger/v0_1_0/`. Требуется Lua 5.2, включая MoonSharp/LuaCs; клиент и сервер. Внешних зависимостей, игрового API и C#-моста нет. Загрузка модуля и создание экземпляра ничего не выводят.

## Создание и уровни

`logger.new(options)` возвращает независимый экземпляр. Все три поля обязательны, значений по умолчанию нет:

- `level` — `trace`, `debug`, `info`, `warning` или `error`.
- `prefixes` — плотный массив непустых строк; `{}` означает отсутствие префиксов.
- `write(line)` — функция вывода; для консоли передаётся `print`. Получает одну готовую строку без завершающего перевода строки.

Массив префиксов копируется, `write` сохраняется по ссылке. Последующее изменение таблицы настроек не влияет на экземпляр. Неизвестные настройки, отсутствие обязательных значений и неверные типы вызывают строковую ошибку Lua. Настройки существующего экземпляра не меняются через публичный API.

**Пример:**

```lua
local logger = require("limanchel.pkg.logger.v0_1_0.logger")
local log = logger.new({ level = "info", prefixes = { "ASS", "storage" }, write = print })
log:info("Хранилище открыто")
```

```text
[ASS][storage][INFO] Хранилище открыто
```

Методы `trace`, `debug`, `info`, `warning`, `error` принимают строку сообщения, в том числе пустую. Выводятся уровни не ниже порога в порядке `trace < debug < info < warning < error`. Все методы возвращают `nil`; `error` только выводит сообщение. Подавленный вызов не проверяет аргументы и не вызывает `write`; аргументы до вызова вычисляются обычным образом в Lua.
