# Избранное

`favorites` — свойство конкретного `storage`, хранящее список избранных типов предметов. Список общий для всех игроков. Термины закреплены в [словаре](../../glossary.md).

## Состав списка

Игрок добавляет отдельные типы предметов в список и удаляет их. Категории и физические экземпляры не используются. Состояние, качество и вставленные предметы не учитываются.

**Пример:** можно добавить «резак», но нельзя отдельно выбрать «резак с кислородным баллоном».

## Независимость списка

Список не зависит от наличия предметов в хранилище. Изменение содержимого не меняет избранное.

У каждого хранилища собственный список. Списки не наследуются и не объединяются с избранным внешних или вложенных хранилищ.

## Общий доступ и сохранение

Изменения списка общие для всех игроков. Список сохраняется у хранилища и не сбрасывается при перезагрузке игры или загрузке сохранения.
