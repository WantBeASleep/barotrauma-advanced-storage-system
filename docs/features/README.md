# Фичи мода

Порядок чтения: от назначения мода и свойств хранилищ к интерфейсу и взаимодействию с контейнерами. Описания фиксируют договорённости о поведении, а не подтверждают готовность реализации. Предложения и открытые вопросы не считай принятыми решениями.

## Контекст

1. [Фундамент мода](../foundation.md) — какую проблему решаем и какой игровой опыт сохраняем.
2. [Словарь](../glossary.md) — общие значения `storage`, `filters`, `favorites` и `Item`.

[Архитектура хранилищ](../superpowers/specs/2026-11-04-storage-architecture-design.md) — утверждённая основа `storage`, отдельные контракты фич и границы дальнейших исследований.
