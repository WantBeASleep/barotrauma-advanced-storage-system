# Фильтрация приёма

`filters` — свойство конкретного `storage`, позволяющее игроку ограничить приём предметов и поддерживать выбранный порядок. Термины закреплены в [словаре](../../glossary.md).

## Режим фильтрации

Игрок выбирает один вариант:

| Режим | Действие собственного фильтра |
| --- | --- |
| Выключен | Не ограничивает приём |
| Белый список | Разрешает только предметы из списка |
| Чёрный список | Запрещает предметы из списка |

## Начальные настройки

По умолчанию фильтр выключен, список пуст, опция «Применять к вложенным хранилищам» выключена.

## Общий доступ и сохранение

Настройки фильтра общие для всех игроков. Режим, состав списка и опция «Применять к вложенным хранилищам» сохраняются у хранилища и не сбрасываются при перезагрузке игры или загрузке сохранения.

## Состав списка

В список можно добавлять категории игры и отдельные типы предметов. Их можно сочетать; достаточно совпадения с любой записью. Теги не используются.

Категории и их названия берутся из игры. Для выбора доступны все категории независимо от наличия в них предметов, пригодных для хранения. Предмет соответствует категории, если его тип относится к ней в игре.

## Применять к вложенным хранилищам

Отдельная опция для фильтра:

- **Выключена:** фильтр действует только на само хранилище.
- **Включена:** фильтр также действует на все вложенные хранилища на любой глубине.

Получатель учитывает собственный фильтр и все распространяющиеся на него фильтры внешних хранилищ. Предмет должен пройти каждый из них. Отключение собственного фильтра не отменяет унаследованные ограничения.

**Пример:** в шкафу находится контейнер, а в нём — субконтейнер.

| Хранилище | Собственный фильтр | Применять к вложенным |
| --- | --- | --- |
| Шкаф | Только категория «Снаряжение» | Выключено |
| Контейнер | Только категория «Материалы» | Включено |
| Субконтейнер | Только железная руда | Выключено |

Непосредственно в шкаф можно положить только снаряжение, в контейнер — материалы, в субконтейнер — только железную руду. Фильтр шкафа внутрь не распространяется. Субконтейнер учитывает фильтр контейнера, даже когда собственное распространение выключено.

## Проверка при помещении

Фильтры проверяются при ручном помещении и автоскладывании. При отказе предмет остаётся в источнике. Собственные ограничения хранилища также сохраняются.

Проверяется только помещаемый предмет. Если это контейнер, его содержимое рекурсивно не проверяется, даже при включённом применении фильтра к вложенным хранилищам.

**Пример:** шкаф запрещает морфин и распространяет фильтр внутрь. Разрешённый кейс с морфином можно положить в шкаф; имеющийся морфин останется в кейсе, но добавить новый уже нельзя.

## Уже лежащие предметы

Изменение фильтров не перемещает и не скрывает содержимое, не мешает его забирать. При повторном помещении действуют текущие правила.
