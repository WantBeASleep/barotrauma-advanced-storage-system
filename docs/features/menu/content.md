# Содержимое

[К обзору меню](README.md)

## Область списка

Вертикальный прокручиваемый список предметов текущего хранилища и всей вложенности. Вложенные кейсы и контейнеры в списке не отображаются: для них остаются стандартные слоты игры. Отсутствие собственного меню у кейса не исключает его содержимое из списка.

Предметы во встроенных слотах оборудования отображаются только внутри [строки оборудования](item-row/README.md), без самостоятельных строк.

Если предметов для отображения нет, в том числе из-за поиска или выбранных категорий, область списка остаётся пустой: без строк, поясняющих надписей и заглушек.

## Группировка

Совместимые для ванильного стака предметы объединяются в строку с общим количеством независимо от мест хранения. Численный лимит стака не делит строку. Несовместимые предметы отображаются разными строками, нестакуемые — поштучно.

Строка представляет конкретный набор предметов игры (`Item`, см. [словарь](../../glossary.md)). Группировка меняет только отображение: каждый предмет сохраняет состояние и содержимое.

## Порядок строк

Сначала идут строки типов из избранного текущего хранилища, затем остальные. Внутри обеих групп — по названию. При любой сортировке избранное сохраняет приоритет. Строки не дублируются; отсутствующие в запасе типы не показываются.

Изменение избранного сразу обновляет порядок строк, независимо от того, открыто ли [окно его настройки](favorites.md).

## Поиск и фильтры отображения

Над списком — поле поиска по названию; справа — кнопка со значком фильтра. Нажатие раскрывает под поиском вертикальный список категорий с прокруткой; повторное нажатие сворачивает его, сохраняя выбор. Можно выбрать несколько: показываются предметы любой выбранной категории. Без выбора категории не ограничивают список.

Название и категории применяются совместно ко всем строкам, включая избранные. Они меняют только видимый список, не правила приёма предметов. При повторном открытии меню запрос и выбранные категории сбрасываются.

## Обновление

Список сразу отражает изменения количества и состояния предметов в текущем хранилище и всей учитываемой вложенности. При помещении или извлечении контейнера его содержимое добавляется в список или исчезает из него.

При обновлении содержимого сохраняется положение видимой строки на экране, а не только численное смещение прокрутки. Появление или исчезновение строк выше не должно сдвигать текущую область просмотра. Если сама строка исчезла, её место занимают соседние; список не сбрасывается в начало.

У сохранившихся строк введённое количество сохраняется и [перепроверяется по актуальному запасу](item-row/README.md#ввод-количества). Для новых строк начальное количество — `1`. При исчерпании запаса строка исчезает.
