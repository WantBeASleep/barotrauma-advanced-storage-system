# Общий макет меню

[К обзору меню](../README.md) · [Открыть HTML-макет](prototype.html)

Образец желаемого вида для последующей реализации средствами UI Barotrauma. Размеры и выравнивание уточняются в игре.

## Расположение

- Верхняя панель: избранное, фильтры приёма; справа — вместимость.
- Ниже: поиск по названию и кнопка со значком фильтра; под ними раскрывается вертикальный список категорий с прокруткой.
- Основная область: прокручиваемый список с готовой [строкой предмета](../item-row/README.md).

## Границы черновика

Поиск, выбор нескольких категорий, избранное в строках и получение работают на демонстрационных данных. Обновление страницы возвращает исходное состояние. Вместимость показана условным числом; девять категорий — условными примерами для проверки списка и прокрутки, их источник ещё не определён. Окно избранного открывается поверх меню и перемещается за заголовок. В нём работают удаление и поиск по демонстрационному каталогу из девяти типов, включая отсутствующие в запасе; изменения сразу видны в основном списке. Окно фильтров приёма также перемещается поверх меню: режим, применение к вложенным хранилищам, категории и типы предметов. Добавление и удаление работают на демонстрационных данных; настройки сохраняются при закрытии окна, но не связаны с игровым приёмом предметов. Основной список от них не меняется. Кнопка фильтров показывает режим цветом лотка с галочкой, внешние ограничения — верхней стрелкой, распространение собственного фильтра — нижней.

Разметка и стили строки взяты из отдельного макета. Правило ограничения количества запасом действует в обоих макетах. Порог компактного вида учитывает рамку и прокрутку общего меню. Изображения используются из `../item-row/assets/`.

## Просмотр

Из этой папки: `node preview-server.cjs`, затем http://127.0.0.1:8766/prototype.html. Сервер строки использует отдельный порт 8765.

После правок проверять макет в браузере: обычную и узкую ширину, обе стороны порога 620 px, прокрутку, изменённые действия, отсутствие наложений, обрезки и ошибок JavaScript. Перед показом возвращать обычную ширину и исходные данные.

Для примера с действующими внешними фильтрами откройте `prototype.html?inherited=1` (через сервер: http://127.0.0.1:8766/prototype.html?inherited=1). Этот параметр задаёт демонстрационное окружение хранилища, а не настройку игрока. По умолчанию внешние фильтры не действуют.

## Отдельная проверка без окон пользователя

`node check-preview.cjs [папка-снимков]` запускает фоновый Edge с временным профилем и открывает HTML напрямую, без сервера и доступа к пользовательским вкладкам. Нужны установленный Edge и пакет Playwright, доступный Node.js (в том числе через `NODE_PATH`).

Проверяются ширины 1000, 621, 620, 390 и 320 px, пересечения блоков строки, выход за границы, поиск, категории, избранное, получение и прокрутка. Снимки и `report.json` сохраняются в указанную папку; по умолчанию — в `barotrauma-menu-preview` во временной папке системы. Снимки нужно просмотреть: автоматические проверки не заменяют визуальную оценку.
