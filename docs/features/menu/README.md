# Меню хранилища

Меню отображает содержимое конкретного `storage`, позволяет забирать предметы и работать с настройками хранилища. Само ничего не хранит и не задаёт правила хранения. Помещение предметов через меню не поддерживается.

Поддержка меню и состав компонентов задаются для типа хранилища при разработке мода. Игрок состав не меняет. Начальный охват — все шкафы игры и будущие контейнеры нашего мода.

Хранилище определяет условия открытия, удержания и закрытия меню. Меню отвечает за отображение и действия внутри него.

[Общий макет меню](mockup/README.md) — расположение элементов и HTML-прототип.
