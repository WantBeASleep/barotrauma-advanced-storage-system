# Вместимость

[К обзору меню](README.md)

## Отображение

Маленький счётчик «занято / всего» в верхнем углу меню, без всплывающих окон и детализации. Если компонент включён, он всегда виден; при отсутствии контейнеров мода показывает `0/0`.

## Подсчёт

Компонент суммирует занятость и вместимость только контейнеров нашего мода:

- Учитывает текущее хранилище, если это контейнер мода.
- Рекурсивно обходит всю вложенность, включая обычные шкафы и ванильные кейсы, но их собственную вместимость не учитывает.
- Каждый контейнер мода учитывается один раз.

Контейнер предоставляет собственные показатели, без показателей вложенных контейнеров. Компонент получает и суммирует их; правила расчёта и ограничения хранения относятся к фиче контейнера.
