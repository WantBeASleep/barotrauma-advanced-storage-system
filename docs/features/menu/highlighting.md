# Подсветка мест хранения

[К обзору меню](README.md) · [Строка предмета](item-row/README.md)

При наведении на строку в открытом слотовом представлении текущего хранилища подсвечиваются слоты, которые:

- непосредственно содержат хотя бы один предмет из строки;
- содержат вложенное хранилище с хотя бы одним предметом из строки на любой глубине.

Каждый подходящий слот подсвечивается один раз. Совпадения типа или названия недостаточно: учитываются конкретные предметы строки. Само текущее хранилище не подсвечивается. Без открытого слотового представления подсветки нет; при уходе со строки она снимается.

**Пример:** алюминий одной строки лежит в слоте шкафа и трёх контейнерах — подсвечиваются слот с алюминием и слоты всех трёх контейнеров. Для строки отдельного инструмента подсвечивается только его слот либо слот содержащего его контейнера.
