# Фильтры приёма

[К обзору меню](README.md)

## Открытие и область настройки

Кнопка со значком лотка с галочкой в верхней панели меню открывает отдельное окно настройки [filters](../filters/README.md) текущего хранилища. Окно появляется поверх меню, перемещается за заголовок и закрывается крестиком. Изменения применяются сразу, без «Применить».

Окно не редактирует фильтры вложенных хранилищ группой. Распространение ограничения внутрь определяется опцией «Применять к вложенным хранилищам» и правилами фичи `filters`.

## Индикация на кнопке

Цвет лотка с галочкой показывает режим собственного фильтра:

- **Серый:** выключен.
- **Мягкий зелёный:** белый список.
- **Приглушённый оранжево-красный:** чёрный список.

Слева постоянно видны две стрелки, расположенные столбиком. Неактивные — тёмно-серые, активные — светло-кремовые; их подсветка не зависит от цвета лотка.

- **↑:** действуют фильтры внешних хранилищ, даже если собственный фильтр выключен.
- **↓:** собственный фильтр включён и установлен флаг «Применять к вложенным хранилищам».

Обе стрелки могут быть активны одновременно. Состояние читается без наведения; всплывающая подсказка для индикации не используется.

## Элементы окна

Элементы расположены сверху вниз; категории и предметы — отдельными блоками друг под другом.

- При действующих внешних фильтрах в самом верху — жёлтая надпись «Действуют фильтры внешних хранилищ». Она остаётся видимой при выключенном собственном фильтре; без внешних ограничений не показывается. Отдельный список внешних фильтров не выводится.
- Режим: «Выключен / Белый список / Чёрный список» с коротким пояснением выбранного действия.
- Переключатель «Применять к вложенным хранилищам».
- **Категории:** прокручиваемый список записей с кнопками удаления; «Добавить категорию» открывает выбор из готового набора.
- **Предметы:** прокручиваемый список типов с иконками, названиями и кнопками удаления; «Добавить предмет» открывает поиск по названиям всех типов предметов игры. Выбор результата добавляет тип в список.

Игрок выбирает готовые категории и типы предметов; собственные категории не создаёт.
