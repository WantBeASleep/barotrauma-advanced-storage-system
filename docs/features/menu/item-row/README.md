## Элементы

- **Иконка и название предмета:** название справа от иконки.
- **Запас:** общее количество предметов в строке по всем местам хранения. Всегда отображается в нижнем правом углу иконки.
- **Состояние:** процент с ванильным плавным переходом цвета от красного через оранжевый к зелёному. Полное состояние показывается как зелёные `100%`.
- **Качество:** надпись и цветное обрамление иконки в духе оригинала, только для нестандартного качества.
- **Встроенные слоты:** только просмотр; для группы — слоты первого предмета. При большом числе слотов — внутренняя прокрутка.
- **Избранное:** строки избранных типов выделяются приглушённым золотистым фоном.
- **Быстрые действия:** расширяемый блок кнопок других фич. Сейчас только звёздочка — переключает тип в [избранном текущего хранилища](../favorites.md). Кнопок добавления в фильтры приёма нет.
- **Количество для получения:** по умолчанию `1`; при обновлении строки и после нажатия «Взять» сохраняется, пока укладывается в актуальный запас.
- **«Взять»:** забирает указанное количество. Клик по строке и перетаскивание предметы не забирают.

## Ввод количества

При реализации за основу берём ввод и проверку количества из ванильного окна покупки у торговца. Его поведение для пустого поля, нуля, отрицательных, дробных и нечисловых значений проверяем по исходникам игры. Если штатных проверок недостаточно для правил получения, дополняем их своими. Согласованное ниже ограничение по запасу строки сохраняется.

После завершения ввода значение выше текущего запаса строки автоматически уменьшается до этого запаса. Завершение ввода — уход из поля или подтверждение получения. Во время набора значение не меняется. Ограничение учитывает запас всей строки, а не лимит ванильного стака.

При изменении запаса, в том числе после получения, завершённый ввод перепроверяется: допустимое значение сохраняется, превышающее запас уменьшается до него. Во время набора перепроверка откладывается до выхода из поля или подтверждения получения и использует актуальный запас. При нулевом запасе строка исчезает.

**Пример:** в строке 12 предметов; игрок вводит `100` и выходит из поля — остаётся `12`. Если затем другой игрок забирает 10 предметов, значение уменьшается до `2`.

## Получение

Берутся первые N предметов из набора строки, без выбора источника игроком или дополнительных приоритетов. Получатель — инвентарь персонажа, размещение следует ванильным правилам.

Если предметов меньше, чем запрошено, берётся доступное количество. Если оно не помещается целиком, переносится помещающаяся часть; остаток остаётся в источниках.

При полном или частичном отказе из-за нехватки места строка подсвечивается красным с анимацией по аналогии с игрой. Текстовая причина не выводится.

## Подсветка мест хранения

При наведении на строку включается [подсветка мест хранения](../highlighting.md) её предметов. Строка не раскрывается для показа распределения запаса.
