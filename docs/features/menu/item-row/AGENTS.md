# Проверка макета

- После правок `prototype.html` проверяй результат в браузере: скриншот, отсутствие наложений и обрезки, работу изменённых элементов и ошибки JavaScript.
- Для просмотра запусти `node preview-server.cjs` из этой папки и открой `http://127.0.0.1:8765/prototype.html`. Если сервер уже работает, используй его. После изменения файла обнови страницу.
- Проверь обычную и узкую ширину, а при изменении адаптации — обе стороны порога переноса. Учитывай фактическую ширину страницы и масштаб экрана.
- Верни обычный размер окна и исходные тестовые данные перед показом пользователю. Если проверка недоступна, явно сообщи об этом; чтение HTML не заменяет визуальную проверку.
