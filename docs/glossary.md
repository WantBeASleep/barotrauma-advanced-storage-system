# Словарь терминов

Названия и значения ниже едины для документации и кода мода. Новые термины и изменения определений сначала согласуем и фиксируем здесь.

| Термин | Значение |
| --- | --- |
| `storage` | Объект, который хранит предметы: шкаф, кейс, контейнер или другое хранилище. Термин не определяет внутренний способ хранения. |
| `filters` | Свойство конкретного `storage`, задающее фильтрацию приёма: режим белого или чёрного списка, его состав и применение к вложенным `storage`. Фильтрацию можно отключить. |
| `favorites` | Свойство конкретного `storage`, хранящее общий для всех игроков список избранных типов предметов, независимый от содержимого хранилища. |
| `Item` (экземпляр предмета) | Конкретный существующий в игре предмет со своим типом, состоянием и местонахождением. Даже при совпадении типа и всех свойств два предмета остаются разными экземплярами. Каждый предмет ванильного стака — отдельный `Item`. |
