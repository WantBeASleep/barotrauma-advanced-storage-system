## Замечания и результат

Критических замечаний нет. Четыре существенных замечания исправлены:

| Дефект | Исправление и проверка |
| --- | --- |
| Частичный конструктор специального типа оставляет дерево | До конструктора сохраняются существующие корни; аварийная очистка удаляет только добавленный корень ожидаемого типа. ContextMenu, MessageBox, SerializableEntityEditor: регрессии сначала падали, затем прошли. Настоящий пустой ContextMenu проверен в клиенте: ошибка возвращена, число корней не изменилось, чужое окно сохранено |
| Image теряет тип scaleToFit при выборе перегрузки | Выбор учитывает реальные значения и присутствие явного nil. Тест порядка sourceRect/enum сначала падал, затем прошёл; создание с enum и sourceRect прошло в клиенте |
| Ссылка внутри ContextMenuOption разрешается слишком рано | Предварительная проверка проверяет допустимость вложенных ссылок; преобразователь вызывается с объектами при создании. Регрессия сначала падала, затем прошла; проверена в клиенте |
| Возвращённая ошибка defer_cleanup теряется | Учитываются и исключение, и nil, err; выполненные действия удаляются из очереди. Регрессия сохраняет исходную и cleanup-ошибку |

Замечание об остановке тестового стенда повышено с Minor до Important: оставшиеся обработчики держат сессию, а прежний stop запрещал повтор очистки. Исправлено: независимые действия продолжаются, неудавшиеся повторяются; открытый пример сохраняется при отказе close. Обе регрессии сначала падали, затем прошли.

Отложено одно Minor: протокол ready не учитывает открытую игровую консоль. Перед снимком её требуется скрыть по README; автоматическое ожидание двух кадров именно после скрытия пока не реализовано.
