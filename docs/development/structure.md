# Структура проекта и пути

Не привязывай код к абсолютным путям конкретного компьютера. Вычисляй пути относительно скрипта, проекта или каталога игры. Вспомогательные файлы храни в проекте или каталоге установки Barotrauma.

## Размещение файлов

| Каталог | Назначение |
| --- | --- |
| `Lua/Autorun/` | Точки входа LuaCs; основной код подключается из модулей. |
| `Lua/<namespace>/` | Код модов и общие пакеты — по [соглашению о пакетах](packages.md#размещение-и-имена). |
| `Lua/<namespace>/<mod-name>/` | Код текущего мода. |
| `CSharp/` | C#-код: `Client/` и `Server/` для соответствующих сторон, `Lib/` для общих компонентов. |
| `assets/` | Ассеты, загружаемые игрой. |
| `source/` | Исходники ассетов, референсы и шрифты. Не загружаются в релизную сборку. |
| `preview/` | Изображения для публикации. |
| `tools/` | Проектные утилиты; каждой утилите — отдельный каталог с README. |
| `bin/` | Локальные бинарники инструментов разработки. |

Создавай каталоги по необходимости. Правила ведения документации — в [docs/AGENTS.md](../AGENTS.md).
