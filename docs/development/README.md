# Разработка

Проектные соглашения:

- При добавлении или переносе файлов — [structure.md](structure.md).
- При создании, изменении или поставке общих Lua-пакетов — [packages.md](packages.md): размещение, SemVer и согласование несовместимых изменений.
- При работе с игровым кодом — [coding.md](coding.md): Lua first, стороны выполнения, стиль, ошибки и правила проверок.
- Для запуска форматирования и линта — [tooling.md](tooling.md): команды.
- При подготовке публикации — [publishing.md](publishing.md).

Пути и команды в соглашениях указаны относительно корня репозитория.
