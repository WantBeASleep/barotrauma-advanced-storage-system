# Advance Storage System

Мод для Barotrauma про удобное хранение вещей и порядок на подлодке. Наша цель — сократить рутину с поиском и перекладыванием предметов, чтобы больше времени оставалось на игру, особенно в команде.

Развиваем привычный опыт хранения Barotrauma: делаем его удобнее, сохраняя связь с игровым процессом и знакомыми игроку принципами.

## Состояние разработки

Поведение мода описано в [документации фич](docs/features/README.md); реализация ещё не начата. `ModConfig.xml` подключает только пустую точку входа `Lua/Autorun/main.lua`. C# мода отключён: записей `Assembly` и рабочего каталога `CSharp/` нет.

Прежние Lua-библиотеки находятся в `archive/lua/lib/`, C#-библиотеки `Storage` и `UrlOpener` вместе с шаблоном подключения — в `archive/csharp/`. Архив не подключён к моду; его настройки и инструкции сохранены как исторический материал.

Перед реализацией — [правила разработки](docs/development/README.md).
