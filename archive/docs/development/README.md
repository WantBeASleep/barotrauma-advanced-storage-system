# Разработка

Читай документы по текущей задаче. Ссылки ниже указаны относительно этого файла.

- При добавлении или переносе файлов — [structure.md](structure.md).
- При создании, изменении или поставке общих Lua-пакетов — [packages.md](packages.md): размещение, SemVer и согласование несовместимых изменений.
- При работе с игровым Lua-кодом и C#-библиотеками — [runtime.md](runtime.md).
- При настройке редактора, изменении Lua-кода или инструментов — [tooling.md](tooling.md): условия проверок и команды.
- Для выбора подходящих навыков — [skills.md](skills.md).
- Для исследования возможностей Lua ↔ C# и проверки правил скилла — [отчёт по мосту](../research/lua-csharp-bridge/README.md).
- При подготовке публикации — [publishing.md](publishing.md).
- При первоначальной настройке нового мода — [руководство по шаблону](../template/README.md).

Пути в примерах внутри руководств указаны относительно корня репозитория.
Команды запускай из корня репозитория, а не из папки документации.
