# Навыки агентов

Папка `.codex/skills` содержит локальные инструкции для AI-агентов:

- [lua-style](../../.codex/skills/lua-style/SKILL.md) — правила Lua-кода: контракты, аннотации, структура модулей, зависимости, ошибки и логирование.
- [barotrauma-code-style](../../.codex/skills/barotrauma-code-style/SKILL.md) — контекст Barotrauma для применения правил Lua: источники контрактов и выбранный API ошибок.
- [lua-csharp-bridgev2](../../.codex/skills/lua-csharp-bridgev2/SKILL.md) — мост Lua ↔ C#: типы, конструкторы, преобразования, коллекции, callbacks и диагностика на основе исследования платформы.
- [lua-csharp-bridge](../../.codex/skills/lua-csharp-bridge/SKILL.md) — предыдущая редакция правил моста, сохранена для сравнения.
- [luacs-docs](../../.codex/skills/luacs-docs/SKILL.md) — документация всей платформы LuaCsForBarotrauma: Lua, C#, API клиента/сервера, подключение модов, конфигурация, установка и диагностика.
- [barotrauma-modding](../../.codex/skills/barotrauma-modding/SKILL.md) - XML, content packages, overrides, StatusEffects и
  документация Barotrauma modding.
- [item-art](../../.codex/skills/item-art/SKILL.md) - item icons и sprites в стиле Barotrauma.
- [scripts](../../.codex/skills/scripts/SKILL.md) - проектные Python-утилиты с README и встроенной справкой на русском языке.

[К оглавлению разработки](README.md).
