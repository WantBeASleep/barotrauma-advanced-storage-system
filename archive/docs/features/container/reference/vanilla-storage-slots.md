# Слоты ванильных хранилищ

[К контейнерам](../README.md)

## Названия

В геймдизайне мода используем **предметные слоты** и **слоты для контейнеров**. «Слоты расширения» — синоним второго термина, а не название отдельной механики улучшения шкафа.

В проверенных русских и английских файлах локализации отдельного названия этих мест под кейсы не найдено. Поэтому выбранное русское название является термином нашей документации.

## Соответствие файлам игры

В установленной игре определение `mediumsteelcabinet` содержит основную секцию `ItemContainer` и дополнительную группу `SubContainer`. Основная секция принимает `smallitem,mediumitem` и исключает `mobilecontainer`; дополнительная группа принимает `mobilecontainer`. См. [containers.xml](../../../../../../Content/Items/Containers/containers.xml), строки 17–25.

Это подтверждает разделение мест под обычные предметы и переносные контейнеры для этого шкафа. Число мест и их наличие зависят от конкретного шкафа.

В исходном коде `SubContainer` добавляет группу слотов с собственными ограничениями к общему инвентарю. Это более общий механизм, чем «слоты только для контейнеров»: допустимые предметы задаются отдельно. Источник: [ItemContainer.cs в репозитории разработчиков](https://github.com/FakeFishGames/Barotrauma/blob/master/Barotrauma/BarotraumaShared/SharedSource/Items/Components/ItemContainer.cs).

## Следствие для требований мода

Базовый контейнер не имеет слотов для контейнеров и не принимает переносные хранилища через обычное размещение. Для реализации недостаточно только убрать `SubContainer`: нужно также обеспечить соответствующие ограничения приёма предметов.

Наличие у предмета внутреннего инвентаря само по себе ещё не делает его переносным хранилищем в смысле этого правила. Техническую классификацию предметов уточним при реализации.

В XML также есть правила совместимости для старых сохранений, меняющие ограничения шкафов. Совместимость с существующими сохранениями потребуется проверить отдельно; текущая заметка описывает определения предметов, а не поведение каждой уже сохранённой лодки.
