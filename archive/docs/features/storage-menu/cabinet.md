# Меню шкафа

[К обзору фичи](README.md)

**Статус:** открытие панели, область списка и счётчик приняты; оформление и дополнительные действия обсуждаются.

## Открытие и область списка

**Принято 20 октября 2026 года.** При открытии шкафа остаются привычные предметные слоты и нижний ряд установленных контейнеров. Одновременно сбоку от слотов автоматически открывается меню с общим списком и поиском.

Меню привязано к шкафу и работает даже без контейнеров нашего мода. Список включает предметы обычных слотов, содержимое ванильных кейсов и контейнеров нашего мода. Через него можно находить и получать вещи, не открывая отдельно каждое вложенное хранилище.

Список и поиск рекурсивно охватывают всю допустимую вложенность. Предметы на любом уровне доступны для поиска и получения. Если особый контейнер допускает вложенное хранилище, его содержимое также включается.

Счётчик и подсказка показывают заполнение только контейнеров нашего мода. Область счётчика уже области общего списка. Формула, пример и детализация описаны во [вместимости контейнера](../container/README.md#суммарный-счётчик-в-меню-шкафа).

## Предложения по UI

- Показывать место хранения и распределение запаса по контейнерам.
- При наведении на ресурс в списке подсвечивать контейнеры, где он есть. Это предложение, а не окончательно выбранное поведение.
- Поддержать категории общего списка, предусмотренные исходным замыслом.
- Добавлять действия над шкафом там, где они нужны; конкретный набор дополнительных кнопок пока не выбран.

Пример представления: «Алюминий — 54», раскрытие показывает распределение по контейнерам. Это пример, а не лимит.
