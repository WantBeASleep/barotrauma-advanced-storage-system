# Меню контейнера

[К обзору фичи](README.md)

**Статус:** интерактивное меню по наведению на контейнер мода в слоте принято; поведение окна и открытие вне шкафа обсуждаются.

## Открытие и содержимое

**Принято 20 октября 2026 года.** При открытом шкафе игрок наводит мышь на контейнер нашего мода прямо в слоте. Открывается интерактивное меню его содержимого; контейнер остаётся в шкафу. Через меню можно работать с содержимым, искать и получать вещи.

Это окно взаимодействия, а не только подсказка с перечнем. Оно показывает запас выбранного контейнера и его собственный [счётчик заполнения](../container/README.md#счётчик-конкретного-контейнера).

Принятое открытие по наведению относится к контейнерам нашего мода. Такое же отдельное всплывающее окно для ванильных кейсов пока не согласовано; их содержимое уже доступно через общий список шкафа.

## Поведение окна

**Предложение для UI.** Сохранять окно при переходе указателя со слота внутрь меню, чтобы игрок мог взаимодействовать с содержимым. Задержка открытия и закрытия, закрепление, размеры и расположение обсуждаются.

Как открывать меню при переноске или самостоятельном использовании контейнера вне шкафа, ещё предстоит определить. Специализированные контейнеры используют это же меню; дополнительные сведения для [генов](../specializations/README.md#контейнер-для-генов) уточняются в описании соответствующего типа.
