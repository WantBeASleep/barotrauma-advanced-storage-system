# Поиск по подлодке

[К графу фич](../../README.md) · [Вопросы этой фичи](#открытые-вопросы)

**Статус:** обсуждение.

## Назначение

Как найти нужную вещь в шкафу и на лодке.

**Исходный замысел.** Найти все места на подлодке, где хранится нужный предмет.

## Сценарий использования

**Исходный замысел.** Игрок вводит название предмета и получает сведения о количестве и обо всех местах его хранения в пределах выбранной области поиска на подлодке.

Где вызывается поиск, как показаны результаты и можно ли получать найденные предметы удалённо, ещё не решено.

## Правила работы

Поиск внутри локальной области уже входит в [единое меню хранения](../storage-menu/README.md) в контекстах контейнера и шкафа. Поиск по всей лодке — отдельная функция; принятый локальный доступ не означает разрешение удалённого получения.

**Предложение для поиска по лодке.** Стремиться охватывать обычные шкафы и контейнеры, иначе забытые вне системы предметы останутся невидимыми.
