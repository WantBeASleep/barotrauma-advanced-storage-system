# Боты

[К графу фич](../../README.md) · [Вопросы этой фичи](#открытые-вопросы)

**Статус:** обсуждение.

## Назначение

Как экипаж под управлением игры соблюдает порядок и получает вещи.

**Исходный замысел.** Боты должны учитывать систему хранения, обычно предпочитать контейнеры и уважать сценарии хранения прямо в шкафу.

## Сценарий использования

**Предложение для обсуждения.** Бот выбирает допустимое место для предмета с учётом назначения хранения, правил пользователя и свободного места, сохраняя запас быстрого доступа. Для своих задач он должен уметь получить нужные вещи обратно.

Приоритеты, команды игрока и техническая возможность такого поведения пока не установлены.

## Правила работы

**Риск.** Правило «контейнер всегда важнее шкафа» уберёт предметы быстрого доступа. Правила помещения бесполезны, если бот не может получить обратно нужный ему предмет.

**Предложение.** Приоритет определяется назначением хранения. Бот учитывает допустимость предмета, явное правило пользователя, защищённый запас быстрого доступа и свободное место. Контейнер используется как предпочтительное место среди подходящих вариантов.

Принцип включения автоматизации по запросу относится к функциям мода и сам по себе не меняет обычное поведение ботов. Способ управления новыми действиями ботов ещё нужно определить.
