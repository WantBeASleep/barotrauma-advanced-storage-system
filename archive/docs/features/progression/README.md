# Грейды и качество

[К графу фич](../../README.md) · [Вопросы этой фичи](#открытые-вопросы)

**Статус:** обсуждение.

## Назначение

Зачем улучшать контейнеры и что дают улучшения.

**Исходный замысел.** Крафт более качественных контейнеров увеличивает вместимость и функциональность.

## Сценарий использования

**Принято как целевой сценарий.** Игрок улучшает контейнер с вещами внутри без предварительной выгрузки. После улучшения содержимое остаётся доступным без потерь, а вместимость соответствует грейду.

Место запуска, ресурсы, длительность и условия выполнения операции ещё обсуждаются.

## Правила работы

**Риск.** Если поиск и удобная выдача открываются поздно, мод сначала воспроизводит проблему, ради которой устанавливается.

**Принято.** Хранение обычных предметов без специализации по категориям, с соблюдением базовых правил вложенности, удобный поиск и простое извлечение через полноценный UI доступны уже у базового универсального контейнера без предварительной настройки.

**Принято.** Грейд определяет верхнюю границу количества предметов в контейнере. Значения должны оставлять смысл и улучшать существующий контейнер, и добавлять новый при наличии свободных слотов для контейнеров.

**Предложение.** Прогрессия также может открывать дополнительные возможности, состав которых ещё нужно выбрать.

### Улучшение заполненного контейнера

**Принято как требование.** Контейнер можно улучшить, пока внутри лежат вещи. Предварительно выгружать содержимое не требуется; после улучшения оно остаётся доступным в улучшенном контейнере без потерь.

**Предлагаемые критерии проверки:** количество и индивидуальные свойства предметов сохраняются; дубликаты не появляются; отмена или прерывание операции не оставляет игрока без контейнера или вещей.

**Открытые вопросы реализации игрового сценария:**

- Где и как запускается улучшение, сколько длится и какие ресурсы нужны?
- Как сохраняются пользовательское имя, фильтры и другие настройки?
- Можно ли пользоваться контейнером во время улучшения, в том числе другому игроку?
- Если будущий вариант улучшения меняет специализацию или иные условия приёма, как обработать несовместимое содержимое без потерь? Такие переходы пока не утверждены.

Способ технического переноса содержимого ещё не выбран. Требование описывает результат для игрока.
