# luafmt

Форматирование и проверка Lua-кода в `Lua/` с помощью локального
`bin/stylua.exe`. StyLua запускается из корня проекта и учитывает `.styluaignore`,
в том числе исключения для сгенерированных файлов.

## Запуск

Нужны Python 3.7 или новее и `bin/stylua.exe`. Дополнительные Python-пакеты не нужны.
Команды ниже выполняются из корня проекта.

Форматирование с перезаписью файлов:

```powershell
python tools/luafmt/luafmt.py
```

Проверка форматирования с выводом различий без изменения файлов:

```powershell
python tools/luafmt/luafmt.py --check
```

Справка:

```powershell
python tools/luafmt/luafmt.py --help
```

## Параметры

- `--check`: проверить форматирование и показать различия без изменения файлов.
- `-h`, `--help`: показать справку и завершить работу.

## Входные данные и результат

- `Lua/`: каталог Lua-кода для форматирования или проверки.
- `.styluaignore`: правила исключения файлов.
- `bin/stylua.exe`: исполняемый файл StyLua.

Без `--check` скрипт может перезаписать файлы в `Lua/`, в том числе при повторном
запуске. В режиме `--check` он только выводит различия. Файлы, соответствующие
правилам `.styluaignore`, пропускаются. Код завершения передаётся от StyLua.

Пути вычисляются относительно расположения скрипта, поэтому его нужно сохранять
в `tools/luafmt/luafmt.py`. Рабочий каталог, из которого вызван скрипт, на выбор
обрабатываемых файлов не влияет.
