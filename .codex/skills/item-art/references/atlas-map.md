# Карта ванильных образцов

[`atlas-index.json`](atlas-index.json) фиксирует версию установленной игры, исходные пути, размеры и SHA-256 атласов и прочитанных XML. [`items.jsonl`](items.jsonl) содержит одну JSON-запись на предмет: её удобно искать через `rg`, затем разбирать только найденные строки. PNG скопированы из игры без изменений.

| Локальный атлас | Содержимое и применение |
| --- | --- |
| `InventoryIconAtlas.png` | Инструменты, оружие, боеприпасы, одежда, медицина, материалы, минералы и электронные компоненты; главным образом инвентарные иконки |
| `InventoryIconAtlas2.png` | Дополнительные компоненты, одежда, водолазное снаряжение, инструменты и предметы талантов; роль конкретной вырезки проверяй по карте |
| `MedicinesSprites.png` | `Content/Items/Medical/Medicines.png`: медицинские ёмкости, шприцы, бинты и препараты; основные спрайты и отдельные иконки |
| `MineralsSprites.png` | `Content/Items/Materials/minerals.png`: материалы, минералы, растения и биологическое сырьё; игровые спрайты и дополнительные состояния |
| `GeneticIconAndSprites.png` | `Content/Items/Genetic/Genetic.png`: генетические материалы, устройства и их детали; иконки, игровые и вспомогательные спрайты |

Старый `CraftingElements1IconAndSprites.png` удалён из подборки: в проверенной версии `1.13.5.0` XML контента не ссылаются на `CraftingElements1.png`. Для актуальных материалов используй `MineralsSprites.png`.

## Поиск

Команды ниже запускаются из папки навыка; из другой папки укажи путь к каталогу:

```powershell
rg -n -i 'бинт|bandage|antibleeding1' references/items.jsonl
rg -n -i 'контейнер|crate|toolbox' references/items.jsonl
rg -n -F '"reference":"GeneticIconAndSprites.png"' references/items.jsonl
```

В имени и описании сохранены тексты русской и английской локализаций игры. Описание помогает установить назначение; `category` и `tags` дополняют поиск. Пустое описание означает отсутствие текста в источнике. Описания могут содержать игровые подстановки; карта не исполняет их. Варианты с одинаковым названием различай по `identifier` и `variant_of`.

## Поля записи предмета

| Поле | Значение |
| --- | --- |
| `identifier`, `name`, `description` | Идентификатор, названия и описания назначения из XML/локализаций |
| `category`, `tags`, `aliases` | Исходные классификаторы и альтернативные идентификаторы |
| `xml`, `variant_of` | Файл определения от корня игры и базовый предмет варианта |
| `item_scale_xml` | XML-значение `scale` предмета с учётом наследования; `null` означает, что оно не задано явно |
| `sprite_color_xml`, `inventory_icon_color_xml` | Цветовые модификаторы предмета, если заданы |
| `images` | Основная иконка и спрайт, а также объявленные дополнительные использования выбранных атласов |

## Поля изображения

| Поле | Значение |
| --- | --- |
| `role` | `inventory_icon` — инвентарь; `world_sprite` — основной спрайт; `auxiliary` — вспомогательное изображение, смысл уточняет `xml_element` |
| `xml_element` | Имя основного элемента либо путь внутри предмета, например `Item/Wearable[1]/sprite[1]` |
| `defined_by`, `xml` | Предмет и XML, задающие изображение; могут принадлежать базовому варианту |
| `texture` | Путь оригинальной текстуры от корня игры |
| `reference` | Имя приложенного PNG; `null` — текстура есть только в установленной игре |
| `rect` | `[x, y, width, height]` в пикселях текстуры от левого верхнего угла; включает прозрачные поля |
| `size_px` | `[width, height]` вырезки, без применения игрового масштаба |
| `within_texture` | Помещается ли вырезка в текстуру; `false` нельзя использовать как готовый образец без проверки XML |
| `attributes` | Атрибуты изображения: `origin`, `scale`, `rotation`, цвет и прочие параметры, если заданы |

`rect` вычисляется из `sourcerect` либо `sheetindex × sheetelementsize`; при отсутствии обоих используется вся текстура. Не режь атласы слепо на клетки `64×64`: встречаются другие размеры. Одна вырезка может принадлежать нескольким предметам; один предмет может использовать несколько изображений.

Основные `Sprite` и `InventoryIcon` учитывают `variantof` и переопределённые атрибуты. Вспомогательные записи отражают объявления в XML, включая контекст компонента; их полное игровое наследование и условия отображения не моделируются. Для выбора размера используй `world_sprite`, а не `Wearable`, `ContainedSprite`, значок слота или эффект. Если отдельной иконки нет, не считай вспомогательное изображение её заменой.

Карта охватывает предметы из манифеста Vanilla, использующие выбранные атласы, и их основные парные изображения из других текстур. Это не каталог всех предметов игры и не разметка каждого нарисованного фрагмента: области без XML-привязок не получают вымышленных имён. При сложных вариантах, отсутствующей записи или изменившейся версии сверяй исходный XML. Формат предмета: [BaroModDoc — Item](https://regalis11.github.io/BaroModDoc/ContentTypes/Item.html).

Обновление PNG и карты: [refresh_references](../scripts/refresh_references/README.md).
