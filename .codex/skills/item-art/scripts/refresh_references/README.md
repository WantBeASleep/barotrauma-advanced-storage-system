# Обновление ванильных образцов

`refresh_references.py` копирует выбранные атласы из установленной Barotrauma и строит карту их использования предметами. Нужен Python 3.10+; сторонних зависимостей нет. Читает только файлы игры, не меняет их.

Из этой папки:

```powershell
python refresh_references.py --dry-run
python refresh_references.py
python refresh_references.py --game-root 'D:\Games\Barotrauma' --output '../../references' --dry-run
```

| Параметр | Действие |
| --- | --- |
| `-h`, `--help` | Показать справку |
| `--game-root` | Корень установленной игры; по умолчанию ищется вверх от расположения скрипта по `Content/ContentPackages/Vanilla.xml` |
| `--output` | Каталог результата; по умолчанию `references` этого навыка |
| `--dry-run` | Прочитать и проверить источники, вывести статистику без записи |

Относительные пути параметров считаются от текущего рабочего каталога. Список выбранных атласов задан в `ATLASES`. При изменении списка обнови также таблицу в `references/atlas-map.md`; скрипт не удаляет прежние файлы.

Вход: `Content/ContentPackages/Vanilla.xml`, перечисленные в нём XML предметов и русской/английской локализаций, PNG выбранных атласов и парных основных изображений. Выход: пять PNG, `atlas-index.json` с версией и хешами источников, `items.jsonl` с предметами. Эти файлы в выходной папке перезаписываются после успешного разбора входов.

Проверяются пути текстур и границы вырезок выбранных атласов; неверные внешние вырезки помечаются `within_texture: false`. Основные иконки/спрайты разрешаются через `variantof`; карта не заменяет движок наследования компонентов. Вспомогательные записи индексируются по объявлениям. Неиспользуемые области атласов не размечаются по догадке. Подробности полей и границ покрытия — в [карте](../../references/atlas-map.md).

После обновления проверь статистику, несколько записей разных типов и соответствующие изображения. Смена версии игры может потребовать изменения парсера. В отчёте `--dry-run` и обычного запуска должны совпадать версия и количества записей; SHA-256 скопированных PNG должны совпадать с `atlas-index.json`.
