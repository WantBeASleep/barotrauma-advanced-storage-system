# Инструкции проекта

Всю документацию, README, коммнетарии и прочее - веди на русском языке.

Перед работой с документацией прочитай `docs/AGENTS.md`.

Перед работой над задачей прочитай [правила разработки](docs/development/README.md), выбери относящиеся к задаче соглашения и следуй им.

При первом знакомстве с модом прочитай [контекст и фичи в указанном порядке](docs/features/README.md). При дальнейшей работе перечитывай относящиеся к задаче разделы.

## Worktree

- Создавай worktree через обычный `git worktree add`.
- Размещай их рядом с исходным проектом: `../<имя-проекта>-worktrees/<имя-задачи>`.
- Не используй встроенные managed worktree Codex.
- Основной рабочий каталог чата оставляй в исходном проекте. Команды для worktree выполняй с явно указанным рабочим каталогом.
- После успешного merge и проверок сам удаляй worktree и слитую локальную ветку без дополнительного подтверждения.
- Удаление выполняй из исходного проекта. Перед удалением проверяй, что все коммиты слиты и нет несохранённых данных. Не используй `--force`.
